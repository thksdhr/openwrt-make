# 硬件与镜像生成设置

- ### ***`Target System` 目标 CPU 架构选择***
    X86/AMD64平台推荐选择 X86

- ### ***`Subtarget` 子目标架构***
    选择 `x86_64`（表示 64 位 x86 架构, 现代软路由均选此项）

- ### ***`Target Profile` 预设设备配置文件***
    X86/64直接选择 `Generic` 即可, 支持绝大多数 Intel/AMD 芯片的软路由和虚拟机
